# Docs

This folder contains planning and delivery documents for moving `Dissonance Surveillance Boulevard` from prototype to production with a BMAD-style workflow.

Documents:

- `bmad-product-brief.md`: product intent, design pillars, constraints, and success metrics
- `scene-architecture-contract.md`: scene ownership rules, node contracts, and authored-vs-procedural policy
- `editor-preview-epic.md`: Godot 4.6 quality-of-life plan for editor-visible scene previews
- `vertical-slice-definition.md`: the target slice that proves the game is ready for production scaling

Current planning priorities:

- refactor the current POC into a production-friendly architecture
- make core content previewable in the Godot 4.6 editor
- define and deliver a polished vertical slice

Recommended reading order:

1. `bmad-product-brief.md`
2. `scene-architecture-contract.md`
3. `editor-preview-epic.md`
4. `vertical-slice-definition.md`
